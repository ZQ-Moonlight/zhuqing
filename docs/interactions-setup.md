## 方案与功能

保留现有 Astro 静态托管，独立 Cloudflare Worker 提供 API，D1 保存数据，Turnstile 防机器人，Cloudflare Access 保护后台，Resend 投递私密联系。相较 Giscus，不要求访客有 GitHub 账号；相较自托管评论服务，不需维护常驻服务器，但需要管理一套 Worker/D1 和邮件服务配置。

公共首页、作品、博客及个人页使用同一组件；24 个公开页面登记到 `backend/interactions/pages.json`。私密/noindex 页面和游戏本体不注入互动。留言记录保留来源页面，审核通过后在全站共享列表展示；点赞和浏览按页面统计，后台按页汇总。评论默认待审，只显示审核通过的纯文本，可回复、拒绝、删除、限制访客；可按页停用互动或明确确认后清零统计。私信仅在后台可见，可标记处理或删除；处理状态独立于投递状态。

## 防滥用与限制

- 点赞、留言、私信均需服务端验证 Turnstile 的成功结果、hostname 和 action。表单还有蜜罐、大小/字段限制、固定收件人、纯文本渲染、参数化 SQL。
- 每 IP 的 Worker 原生限流为 30 次/分钟，总入口为 300 次/分钟；它们按 Cloudflare 节点近似计数，**并非全球严格限额**。额外 D1 原子配额：评论每网络 3 次/10 分钟、全站 100 次/天；点赞每网络 10 次/天、全站 1,000 次/天；私信每网络 3 次/10 分钟、全站 20 次/天；浏览事件全站 10,000 次/天。这些是固定时间桶，重试也可能占配额，UTC 日界附近存在双桶突发。攻击仍可耗尽可用额度，免费计划可能暂停服务。
- 点赞按浏览器随机 ID 去重，并以每月轮换的 IP 摘要限制同网络重复。共享校园/Wi-Fi 网络会少计；换网络、清理浏览器存储或有组织真人可绕过部分保护。点赞目前为一次性表达，没有取消按钮。
- 浏览量为浏览器前台停留 8 秒后发送、按页面/UTC 日期/IP 摘要去重的估算。8 秒检查在前端，可被绕过；不是精准独立访客数，不能用于结算。
- 后台封禁同时限制当前匿名 ID 与当前月网络摘要，网络部分跨月会失效，可能影响同网其他人。私信也检查网络封禁。
- 匿名 ID 存在浏览器 localStorage；站点数据库只存带服务端密钥的 HMAC，不保存原始 IP。原始网络请求仍由 Cloudflare/邮件供应商处理。
- 私信、未公开留言保留 30 天；审计 90 天；浏览去重键约 2 天；定时清理每日运行，因此实际删除可多延迟约一天。公开留言和点赞长期保留，直到管理员删除/清零。D1/供应商备份另有保留期，删除后台记录不等于删除已送达的邮箱副本。
- 请求 ID 绑定内容，重复提交可重试；并发冲突返回 409。Resend 使用同一幂等键重试，未知发送结果超过 23 小时停止自动重试，避免供应商幂等窗口过期后重复投递。`accepted` 仅表示供应商接受，不代表 QQ 入箱；后台不自动重发。
- 后台服务端核验 Access JWT 签名、issuer、audience、有效期和精确管理员邮箱；仅同源 JSON + 自定义标头可修改。隐藏网址不能代替身份校验。未配置 DB、验证或管理员参数均关闭对应功能。

## 费用

按目前公开免费计划，小型个人站可按 **0 元新增月费** 起步（不包括已有域名，未核实账号现有套餐/共享用量，不自动升级）。Workers Free 100,000 请求/天；D1 Free 500 万读取行/天、10 万写入行/天、总共 5 GB（单库最多 500 MB）；单管理员可用 Access 免费计划，Turnstile 有免费计划。Resend Free 3,000 封/月、100 封/天，本实现更保守地限制为 20 次/天。免费套餐超出相应额度会限制请求/查询/发信；付费套餐按其计费规则可能产生用量费用。正式账号套餐未能通过当前令牌核实，不会主动升级套餐。系统没有按累计评论条数收费或限制总条数；数据库容量与查询扫描量会随内容增长，需监控真实用量。

2026-11-06 再次读取官方定价页面核对。Workers Paid 起价 5 美元/月；Resend Pro 起价 20 美元/月。

核对来源：[Workers/D1](https://developers.cloudflare.com/workers/platform/pricing/)、[Access](https://www.cloudflare.com/plans/zero-trust-services/)、[Turnstile](https://developers.cloudflare.com/turnstile/plans/)、[Resend](https://resend.com/pricing)、[原生限流边界](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)。

## 开发、迁移与运维

Node >=22.12。`npm run test:interactions` 使用真实本机 SQLite 和真实签名 JWT，外部身份代理、验证码和发信是模拟；`npm run build` / `npm run build:cloudflare` 构建后重新生成公开页面白名单。新增路由后同步发布 Worker 白名单；只发布静态页会使未登记页面返回 404。

后台在 API 域名 `/admin`。查看待审评论 → 通过或拒绝；回复只随已公开评论显示。私信“已处理”不是“已投递”。敏感删除/清零均需界面确认。每日清理依赖 cron；上线后检查定时任务确实运行，监控免费配额。D1 导出与恢复应由账户拥有者操作并私密存储，导出包含访客私信；恢复前注意已删除数据可能重新出现。后台没有公开导出入口。

代码交付与审核记录位于本次 task 的 `evidence` 和 `interactions-evidence`；仅应用本次白名单补丁，禁止整目录覆盖原仓库中的个人页实验、学习库或媒体。应用前再次核对主分支和未提交改动。所有已有媒体源文件应保持 SHA-256 一致；构建沿用仓库原有的 GIF/视频及 PDF 体积处理逻辑，本任务不改动它们。
