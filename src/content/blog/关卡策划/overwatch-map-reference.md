这份文档收录了 17 张《守望先锋》经典地图俯视图，作为我学习关卡策划时的空间分析资料。整理重点不是记忆地图，而是观察不同目标模式如何组织**主路线、侧翼、高低差、交战节点、视线和攻防节奏**。

> 版本说明：这些图片对应《守望先锋》较早期的经典地图与模式，其中部分地图、模式和具体布局在后续版本中可能已经调整。图片未标注比例尺、出生点、目标点、血包、高度层和版本号，因此适合做宏观结构研究，不能代替当前版本的实机勘察。

## 读图方法

俯视图首先呈现的是**拓扑关系**，不是完整的三维战斗体验。阅读时可以按下面的顺序进行：

1. 先找任务目标与双方可能的出生方向，画出最短的主路线。
2. 再找与主路线平行或交叉的侧翼，记录它们在哪些位置汇合。
3. 标记门洞、窄桥、拐角、庭院和大房间，推测交战节奏的收放变化。
4. 观察长直线、连续转弯和遮挡物，提出视线控制方面的假设。
5. 最后进入游戏验证高度差、跳点、单向出口、掩体尺度、血包位置和实际行进时间。

阅读下面的图片时，可以统一追问三个问题：**玩家为什么会走这里？在这里会看到什么？如果主路受阻，还有什么选择？**

## 突击地图：两个目标点的攻防递进

突击地图由连续的 A、B 两个占领目标组成。俯视图中通常能看到两个相对独立的战斗区，以及连接它们的过渡空间。学习时应重点比较：第一目标前的入口宽度、绕后路线的长度、第二目标附近的防守回场距离，以及两个区域在开阔度上的变化。

#### 阿努比斯神殿 / Temple of Anubis

![阿努比斯神殿经典版本的完整俯视图](./overwatch-map-reference.assets/anubis_map.png)

观察重点：出生区到第一目标之间的开放空间如何收束为入口；第一、第二目标之间如何通过转折与房间串联；不同入口是否会在接近目标时重新汇合。

#### 花村 / Hanamura

![花村经典版本的完整俯视图](./overwatch-map-reference.assets/hana_map.png)

观察重点：街区、庭院与室内目标区之间的空间转换；围绕中心庭院布置的环形关系；狭窄入口与较大目标房间形成的节奏对比。

#### 地平线月球基地 / Horizon Lunar Colony

![地平线月球基地经典版本的完整俯视图](./overwatch-map-reference.assets/horizon_map.png)

观察重点：连续室内空间怎样利用房间形状、通道方向和中庭切分视线；室外月面区域作为特殊支路时，对风险和路线辨识有什么影响。

#### 沃斯卡娅工业区 / Volskaya Industries

![沃斯卡娅工业区经典版本的完整俯视图](./overwatch-map-reference.assets/volskaya_map.png)

观察重点：两个目标区域之间的尺度变化；室外工业广场、建筑内部与边缘通道如何形成不同性质的推进路线。

## 护送地图：沿载荷路线组织阶段

护送地图的核心是一条连续移动的目标路线。路线本身既是任务引导，也是空间节奏线。分析时可以沿载荷前进方向逐段标记：长直线、急转弯、门洞、坡道、室内外边界和终点房间，并思考每一次转折如何重置交战距离与双方站位。

#### 多拉多 / Dorado

![多拉多经典版本的完整俯视图](./overwatch-map-reference.assets/dorado_map.png)

观察重点：曲折街道如何限制超长视线；建筑内部与外部道路之间的平行路线；终段从城市街区进入设施内部后，战斗距离如何变化。

#### 渣客镇 / Junkertown

![渣客镇经典版本的完整俯视图](./overwatch-map-reference.assets/junk_map.png)

观察重点：开阔荒地、弯曲道路与封闭工业空间的三段式差异；路线弯折处如何提供新的防守朝向与侧翼入口。

#### 66 号公路 / Route 66

![66 号公路经典版本的完整俯视图](./overwatch-map-reference.assets/route_map.png)

观察重点：自然地貌和建筑体量如何切断道路视线；从室外峡谷进入室内终点时，空间宽度与交战距离如何逐步压缩。

#### 监测站：直布罗陀 / Watchpoint: Gibraltar

![监测站直布罗陀经典版本的完整俯视图](./overwatch-map-reference.assets/watchpoint_map.png)

观察重点：载荷路线在大型设施中多次转向所形成的阶段感；房间、机库和连接走廊之间如何建立主路与上层或侧向路线。

## 混合地图：从占点转入护送

混合地图把占领目标和护送路线接在一起。其关键不只是“两个模式拼接”，而是让第一目标周围的面状战斗空间，在目标拿下后自然转化为沿路径推进的线性空间。适合比较占点区与护送段在路线数量、方向感和战斗距离上的差别。

#### 暴雪世界 / Blizzard World

![暴雪世界经典版本的完整俯视图](./overwatch-map-reference.assets/blizzworld_map.png)

观察重点：主题区域的视觉分区是否也对应战斗阶段；第一目标周围的多方向接近方式，怎样过渡到后续更明确的载荷路线。

#### 艾兴瓦尔德 / Eichenwalde

![艾兴瓦尔德经典版本的完整俯视图](./overwatch-map-reference.assets/eich_map.png)

观察重点：村落、桥头与城堡内部的空间层次；狭窄入口、开阔庭院和室内终点怎样形成连续但差异明显的节奏。

#### 好莱坞 / Hollywood

![好莱坞经典版本的完整俯视图](./overwatch-map-reference.assets/holly_map.png)

观察重点：城市街区、摄影棚外景与棚内空间的段落转换；每一段场景主题如何帮助玩家辨认当前推进阶段。

#### 国王大道 / King's Row

![国王大道经典版本的完整俯视图](./overwatch-map-reference.assets/kings_map.png)

观察重点：街道连续转弯带来的视线重置；主路两侧的小房间和支路如何提供短距离侧翼；后段室内空间如何收紧战斗。

#### 努巴尼 / Numbani

![努巴尼经典版本的完整俯视图](./overwatch-map-reference.assets/numbani_map.png)

观察重点：第一目标周围的环绕关系；载荷路线上的多次折返与高楼街区形成的遮挡；开放区域和室内通道的交替。

## 控制地图：围绕中心目标制造对称与差异

控制模式通常为同一主题下的三张独立子地图。双方同时向中心目标移动，因此基础结构强调相对公平，但并不意味着完全镜像。应重点比较双方到点距离、入口数量、目标周围的环路、危险边缘，以及不同子地图如何改变近战、远程和垂直机动的价值。

#### 伊利奥斯 / Ilios

![伊利奥斯三张控制子地图的俯视图](./overwatch-map-reference.assets/ilios_map.png)

观察重点：三张子地图采用不同的外轮廓与中心空间；在保持双方到点关系相近的前提下，开放边缘、环形区域和室内外组合如何改变战斗方式。

#### 漓江塔 / Lijiang Tower

![漓江塔三张控制子地图的俯视图](./overwatch-map-reference.assets/lijiang_map.png)

观察重点：矩形、环形和放射状三种中心结构；目标周围的回旋空间、门口数量与支路长度如何影响集结和返场路线。

#### 尼泊尔 / Nepal

![尼泊尔三张控制子地图的俯视图](./overwatch-map-reference.assets/nepal_map.png)

观察重点：三张子地图在开阔度和中心目标包围方式上的差异；近似对称结构中，局部掩体和边缘空间如何制造可辨识的战术位置。

#### 绿洲城 / Oasis

![绿洲城三张控制子地图的俯视图](./overwatch-map-reference.assets/oasis_map.png)

观察重点：圆形、矩形与轴向空间围绕目标形成的不同节奏；外围路线如何在进入目标区前分流，又如何在目标附近重新汇合。

## 从这组俯视图中提炼的设计线索

### 1. 任务结构决定地图骨架

护送地图呈现明显的线性长轴，控制地图则围绕中心目标组织近似对称的两侧动线；混合地图同时具有面状的占点区和线性的护送段。开始设计关卡时，应先明确任务循环，再决定空间外形，而不是先搭一片场景后再寻找目标位置。

### 2. 主路清晰，但不会只有一条路

这些地图通常保留一条最容易理解的主路线，同时利用平行房间、建筑边缘和短支路提供侧翼。支路的价值不只在于绕后，还包括获得不同视角、避开火力、重新集结和快速回到主路。

### 3. 转弯与门洞是节奏控制器

长直线容易形成持续视线压力；转弯、门洞和高体量建筑会切断视线，让推进双方重新判断站位。连续的“展开—收束—再展开”能把一条路线划分为多个可记忆的战斗段落。

### 4. 平面图无法说明全部问题

俯视图容易低估高台、坡度、可跳跃边缘和遮挡高度。两个在平面上相邻的区域，实际可能被楼层、单向落差或封闭墙体隔开。因此，俯视图适合提出假设，实机走图才负责验证。

## 后续分析模板

以后针对单张地图做深入拆解时，可以沿用下面的记录表：

| 分析项 | 需要记录的内容 |
| --- | --- |
| 基本信息 | 模式、版本、攻防方向、目标位置、地图边界 |
| 路线 | 主路、短侧翼、长侧翼、回场路线、路线汇合点 |
| 节点 | 关键门洞、转角、庭院、桥梁、房间和终点区 |
| 高度 | 高台入口、上下层连接、跳点、跌落风险、制高点视野 |
| 视线 | 最长视线、交叉火力位置、遮挡、视线被重置的位置 |
| 资源 | 大小血包、掩体密度、可破坏或可交互元素 |
| 节奏 | 从出生点到首战的时间、阶段转换、团灭后的回场时间 |
| 验证 | 自定义房间实测、录像复盘、不同英雄体型与位移能力测试 |
